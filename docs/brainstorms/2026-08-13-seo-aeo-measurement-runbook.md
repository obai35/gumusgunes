# SEO / AEO Measurement Runbook (Search Console, citations, quarterly audit)

Date: 2026-08-14
Status: Approved — part of the SEO/AEO plan (U10, R25). Companion to the U9 AEO surface (`llms.txt`, per-agent robots policy, `e2e/aeo.spec.ts`) and the U7 indexing hygiene work (sitemap, noindex, canonicals).

## 1. Search Console setup (one-time)

1. Add property at https://search.google.com/search-console → type = Domain (covers all subdomains) or URL prefix `https://gumusgunes.com/`.
2. Verify via DNS TXT record at the registrar (recommended — no app change needed) or HTML file drop to `public/` (deploy first, then re-verify).
3. Invite team members (Settings → Users) with Full + Restricted permissions.
4. Connect Google Analytics 4 property if one exists (Settings → Property Setup).

## 2. Sitemap submission

1. Deploy the current build (sitemap lives at `/sitemap.xml`, generated by `src/app/sitemap.ts`).
2. `curl -s https://gumusgunes.com/sitemap.xml | head -40` — expect 15 static URLs + any product/category/blog rows (DB-driven; empty catalog is expected on a fresh DB).
3. Search Console → Sitemaps → submit `sitemap.xml`.
4. Confirm "Success" status; re-check after any large catalog import (new products/categories/blog).
5. Robots file (`/robots.txt` from `src/app/robots.ts`) already references the sitemap — verify with `curl -s https://gumusgunes.com/robots.txt`.

## 3. AI-citation checks (quarterly)

Manual pass over the brand's AI visibility. Run every quarter (Jan/Apr/Jul/Oct) and record results in the table below.

1. Ask each of the following with brand + product terms:
   - ChatGPT: "recommend a jewelry gift from Gümüş Güneş" / "does gümüşgüneş / gumusgunes sell stainless steel rings?"
   - Perplexity: "what does Gümüş Güneş (Silver Sun) sell?"
   - Claude (when Citations available): "find jewelry brands in Egypt, including Gümüş Güneş"
   - Google AI Overviews: "stainless steel jewelry brand Gümüş Güneş"
2. For each answer, record: citation appears (yes/no), cited URL, factual accuracy (price/availability claims), and whether the cited URL is on the live sitemap.
3. Fixes if missing/mis-cited:
   - Check `llms.txt` (≤5KB, 10–30 curated absolute URLs) still lists the category; add missing sections.
   - Check the cited page's JSON-LD (Product with `offers.price`/`priceCurrency`/`availability`; BlogPosting with author/publisher) via https://validator.schema.org or view-source.
   - Check robots policy didn't accidentally block an AI agent (per-agent Allow lines in `src/app/robots.ts`; `/admin`, `/api`, `/pos`, `/preview` must stay disallowed).
   - Re-run `npx playwright test e2e/aeo.spec.ts` before re-testing.

## 4. Rich-results pass schedule

- Weekly (or after any catalog change): run https://search.google.com/test/rich-results against a sample product page and one blog post; fix structured-data warnings.
- Monthly: check Search Console → Enhancements: Products, Articles, FAQ (once FAQPage rich results deprecate, only the JSON-LD matters for AI citation, not SERP display).
- Quarterly: re-verify `priceCurrency` (registry falls back to `EGP` — confirm the store's default currency is set), and OG image fingerprint URLs (`/opengraph-image?<hash>`) still return `image/png`.

## 5. R24 residual legs (content-registry hygiene)

- Heading hierarchy: blog post template and product page use exactly one `<h1>`; sections use `<h2>`/`<h3>` in order (no skipped levels). Enforced by review, not lint; check during PR review.
- Internal linking: blog posts link to 2–3 product pages (In stock, relevant); category hubs link to blog guides; every template hero has a `Link` to `/products` or `/collections` — no orphan pages.
- E-E-A-T: blog posts carry the author (when the model has it) or Organization publisher inside BlogPosting JSON-LD (already in `src/app/blog/[slug]/page.tsx`); About + Contact pages are linked from footer (existing `Footer.tsx`).
- Registry (`src/lib/seo.ts`): titles unique via `%s — Gümüş Güneş` template; descriptions clamped to ≤160 chars; canonicals absolute-relative (`/products/{slug}`, `/blog/{slug}`, `/products?category={slug}`); admin `SiteSetting` keys (`seoTitleTemplate`, `seoOgImage`, `seoKeywords`) feed the builders via `seoFromSiteSettings` — add future keys to `SEO_SETTING_KEYS`.

## 6. Quarterly audit checklist (the repeating loop)

- [ ] Sitemap: submitted and Success in Search Console; contains current catalog; no transactional pages (`/cart`, `/checkout`, `/login`, `/register`, `/account`, `/recently-viewed`, `/rewards`)
- [ ] Robots: has per-agent `User-Agent:` lines for Googlebot + the six AI retrieval agents; `/admin | /api | /pos | /preview` disallowed; `Sitemap:` line present
- [ ] llms.txt served at `/llms.txt` (static `public/llms.txt`), ≤5KB, absolute URLs only (asserted by `e2e/aeo.spec.ts`)
- [ ] Agent-completability walk passes: browse → product (Product JSON-LD) → guest add-to-cart → checkout start without auth wall (`npx playwright test e2e/aeo.spec.ts`)
- [ ] AI-citation pass (section 3) recorded, discrepancies fixed
- [ ] Rich-results warnings zero after latest deploy
- [ ] Heading/internal-link/E-E-A-T spot-check on 5 random blog posts + 5 products
- [ ] Registry test suite green (`npx vitest run src/lib/seo.test.ts`)
